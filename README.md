# UniFound — Campus Lost & Found Management System

UniFound is a centralized digital lost and found management platform tailored for university campuses. It bridges students, campus security gatehouses, and university welfare directorates to streamline property intake, automated matching, ownership verification, and physical custody handovers.

---

## 🚀 Key Features

- **Three Dedicated Stakeholder Portals**:
  - **Student / Scholar**: Report lost property, log found belongings, browse catalog, file ownership claims, monitor smart match radar.
  - **Security Custody Desk**: Gatehouse property intake, custody safe assignment, claim adjudication, issuance of collection pass codes, handover register sign-off.
  - **Dean / Administration**: Executive overview, recovery KPIs, official printable Custody & Recovery Audit report, chain-of-custody audit logs.
- **Account Registration & Directory Sign-In**:
  - Seamless directory sign-in for students, security officers, and administrators.
  - In-app registration form for new student or security accounts with admission numbers, Kenyan/international phone formats, and faculties.
- **Automated Multi-Factor Matching Radar**:
  - Algorithmic scoring based on Category (40%), Campus Zone (30%), Keyword correlation (20%), and Date proximity (10%).
- **Fraud Prevention & Custody Safe Tracking**:
  - Information asymmetry hides unique identifiers from public views.
  - Two-tier claim verification with secret detail challenge and digital Gatehouse Pass codes (`SEC-UG-XXXX`).
- **Authentic Photographic Previews**:
  - 100% of demo items feature high-resolution photographs (smartcards, ultrabooks, brass room keys with bead lanyards, scientific calculators, smartphones).
